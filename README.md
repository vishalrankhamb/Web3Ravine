# Web3Ravine

Web3Ravine is an open-source, decentralized platform executing smart contracts on a distributed system.

With Web3Ravine, you get a lightweight tool that stays out of your way.

- python

- unittest/pytest

## Installation

1. Clone the repository: `git clone https://github.com/vishalrankhamb/Web3Ravine.git`
2. Install dependencies: `pip install -r requirements.txt`
3. Run the test suite: `pytest`

## Configuration

Web3Ravine is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
